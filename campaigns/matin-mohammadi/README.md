# Matin Mohammadi — Standalone GitHub Campaign Package

400 Directs / 300 Replies / 300 Quotes. Reply-source split preserved at 70/30 using the user-provided reply lists; all quote links come from the user-provided primary list. Includes 10 English posters, 1 Persian cover poster, and 1 real photo.

Texts were built for stronger variety in openings, pacing, argument, and calls to action. They keep the English case hashtag within the body, add the Persian hashtag when space allows, preserve #IranMassacre, and close with #StopExecutionsInIran. Mentions are phrased as requests to press, demand, amplify, scrutinize, spotlight, or call for review.

English-only prose audit: all 1,000 campaign texts were checked so Persian script appears only in the approved Persian hashtag #متین_محمدی, never as an accidental word inside English prose.
