# Ekbatan Case — Standalone GitHub Pages Package

**Milad Armoun / میلاد آرمون** and **Navid Najaran / نوید نجاران**

## Deployment

1. Extract this package.
2. Upload `index.html` and the complete `assets/` directory to the root of a new GitHub repository.
3. In GitHub, enable **Settings → Pages → Deploy from a branch → main → /(root)**.
4. Open the published GitHub Pages site. All poster and post files are local, with no runtime API key or database required.

## Package contents

- 15 individual English advocacy posters (`assets/poster_en_01.png` to `_15.png`). Two poster nameplate errors from earlier generated graphics have been corrected by covering their original labels.
- One Persian cover (`assets/poster_fa_cover.png`), with English hashtags and the photo labels matched to the supplied names.
- Four user-supplied individual/composite images, untouched and labeled as submitted. In the originals, Navid is the man with the mustache and blue shirt; Milad is the man with the swept-back hair in a light jacket.
- 1,500 unique X messages in `assets/posts.js` and exportable `assets/posts.csv`: 1,000 Normal and 500 Premium, subdivided into direct, replies and quote posts.
- Filter/search and a used-post tracker, stored only in the local browser.

**X:** For a native Quote Post, open the source tweet and choose Quote in X. The website can also prepare an X composer with text and a source link. The result depends on X and cannot be guaranteed to be a native Quote Post.

**Legal factual caveat:** A report by Dadban dated 19 November 2026 says the Supreme Court upheld both death sentences and that the case was referred for enforcement. An independently verified execution date is not known. The death sentences from the Revolutionary Court are distinct from the separate criminal court decisions.

**Standalone:** This package does NOT include a return-to-master-index button and does not overwrite or integrate into your existing master index.

Sources are linked directly in `index.html`.
